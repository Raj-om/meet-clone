ABSTRACT / SYNOPSIS

The post-pandemic digital era has established web-based real-time video communication as critical national infrastructure for governance, education, healthcare, and enterprise commerce. However, the prevailing digital ecosystem is predominantly reliant on foreign, proprietary communication suites (e.g., Google Meet, Zoom, Microsoft Teams). These platforms present profound vulnerabilities: opaque data residency pipelines, recurring subscription overheads, lack of domain-specific algorithmic customization, and total vulnerability to sophisticated AI-driven exploits, including deepfake impersonation, cognitive co-pilot malpractice during examinations, and identity spoofing in corporate hiring.

In alignment with the national vision of “Atma Nirbhar Bharat” (Self-Reliant India), this major project presents the design, mathematical formulation, full-stack implementation, and experimental evaluation of “Meet-Clone”—an indigenous, enterprise-grade, intelligent web conferencing ecosystem. The system bridges the gap between low-latency WebRTC media streaming and edge-accelerated cognitive AI intelligence.

The core architecture introduces five key engineering breakthroughs: (1) ARENA (Adaptive Real-time Ensemble Network Architecture) predictive congestion control using second-order RTT derivatives; (2) CHRONOS Cognitive Gap Engine for zero-trust exam integrity; (3) Multimodal Bayesian Risk & 4-State HMM sensor fusion; (4) Autonomous In-Browser Neural Subsystems (Whisper ASR, Silero VAD, ArcFace 128-D Liveness); and (5) A 3-Tier Defensive Security WAF integrated with LiveKit SFU.

KEYWORDS: WebRTC, Atma Nirbhar Bharat, ARENA Congestion Control, Cognitive Gap Algorithm, Bayesian Sensor Fusion, Hidden Markov Model, Deepfake Detection, LiveKit SFU, Whisper Transcription, Biometric Liveness Verification.

CHAPTER 1
INTRODUCTION

1.1 Background & Scope of Work

In the modern interconnected era, real-time audio-visual communication has ceased to be merely a business convenience; it has emerged as critical sovereign digital infrastructure underpinning global education, governance, judicial proceedings, healthcare telemedicine, and corporate enterprise. The global shift toward distributed work environments and remote educational pedagogies has precipitated an exponential surge in video conferencing traffic. The Internet Engineering Task Force (IETF) and World Wide Web Consortium (W3C) standardized Web Real-Time Communication (WebRTC) [1] to enable plugin-free, peer-to-peer browser-based media streaming over Real-Time Transport Protocol (RTP) and Datagram Transport Layer Security (DTLS).

1.2 Problem Statement

Conventional web-based video conferencing platforms fail to provide a sovereign, secure, and domain-adaptive communication architecture. They rely upon reactive network congestion controls that result in frequent video freezes under unstable network conditions, lack client-side cryptographic and behavioral defenses, and provide no integrated intelligence to detect real-time deepfakes, academic malpractice, or cognitive dishonesty. Furthermore, existing proctoring and analytics solutions require expensive server-side GPU clusters that compromise participant privacy by transmitting raw biometric video streams to centralized third-party servers.

1.3 Motivation & Alignment with Atma Nirbhar Bharat

The “Atma Nirbhar Bharat Abhiyan” (Self-Reliant India Mission), championed by the Government of India, emphasizes technological sovereignty, indigenous software creation, and the development of world-class digital public goods. Building an independent, robust, and extensible real-time collaboration ecosystem is a fundamental milestone toward securing India's digital borders and reducing reliance on foreign technological monopolies.

1.4 Project Objectives

  • To Architect a Full-Stack Modern Web Conferencing System using Next.js 16, React 19, Node.js, and PostgreSQL.
  • To Integrate Hybrid Real-Time Media Streaming via LiveKit SFU for sub-150ms latency and Dynacast layer pruning.
  • To Develop the ARENA Congestion & Bitrate Optimization Engine using 2nd-order RTT derivatives and Thompson Sampling.
  • To Formulate the CHRONOS Cognitive Gap Proctoring Algorithm contrasting measured mental strain against task complexity.
  • To Construct a Multimodal Bayesian Risk & 4-State HMM Sensor Fusion Pipeline running in browser RAM.
  • To Deploy a 3-Tier Behavioral Security Firewall & WAF enforcing rate-limiting and payload sanitization.

7.1 Algorithm 1: ARENA Predictive Congestion Control

Standard WebRTC congestion algorithms (GCC) rely upon reactive loss estimators. Bitrates are only throttled after packets are dropped. ARENA calculates 1st and 2nd order finite derivatives of Round-Trip Time over a sliding window:

ΔRTT(t) = RTT[t] - RTT[t-1] .......... (7.1)
Δ²RTT(t) = ΔRTT[t] - ΔRTT[t-1] .......... (7.2)

The normalized congestion probability is mapped through a sigmoid activation function:

P(congestion) = 1 / (1 + exp(-10 × (rawSignal - 0.5))) .......... (7.3)

7.2 Algorithm 2: CHRONOS Cognitive Gap Anomaly Detection

CHRONOS evaluates the neuro-psychometric gap between Expected Task Complexity ($EC$) and Measured Cognitive Load ($MCL$):

MCL = 0.40 × BlinkStrain + 0.40 × GazeStrain + 0.20 × HeadStrain .......... (7.4)
CognitiveGap = Max(0, ExpectedComplexity - MCL) .......... (7.5)
