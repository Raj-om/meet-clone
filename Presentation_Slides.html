Abstract

In alignment with India’s vision of Atma Nirbhar Bharat, this project presents a fully indigenous, browser-native, AI-powered video conferencing platform built using open-source technologies, eliminating dependency on foreign services like Google Meet or Zoom.

The platform uses Next.js 16, React 19, WebRTC, and a custom Node.js + Socket.IO signalling server. It integrates a Random Forest-based scam detection engine fusing six signals; a frequency-domain audio deepfake detector using spectral flatness and ZCR variance; a Lucas-Kanade optical flow engine for puppet-master detection; and a Python-Flask DIRE microservice using DCT power-spectrum analysis for AI-generated video detection.

Beyond security, the platform provides live captions, collaborative whiteboard, breakout rooms, polls, virtual background, noise cancellation, and malicious link / QR-code safety detection — all without any third-party cloud dependency.

Introduction
Video conferencing has transformed education, healthcare, governance, and business in India. The COVID-19 pandemic accelerated reliance on foreign platforms — creating data sovereignty risks. In the spirit of Atma Nirbhar Bharat, there is a critical need for a secure, intelligent, and self-reliant video communication platform developed and hosted within India.
🌐

WebRTC Technology

Peer-to-peer encrypted video and audio without central media servers. Native browser support — no plugins.

🛡️

AI-Powered Security

Real-time deepfake, voice clone, and scam detection using TensorFlow.js and ONNX Runtime in the browser.

🇮🇳

Atma Nirbhar Vision

100% open-source stack. No dependency on Google, Zoom, or AWS. Data stays within the Indian network.

Objectives
1
Design and implement a full-featured, browser-native, P2P video conferencing platform using WebRTC and Next.js — without any third-party media server.
2
Integrate a real-time multi-signal scam detection engine powered by a custom Random Forest classifier fusing six independent detection signals.
3
Implement audio deepfake (voice clone) detection using spectral flatness, noise floor, and zero-crossing-rate variance via the Web Audio API.
4
Implement video deepfake detection using MesoNet-4 ONNX browser inference and a pixel-heuristic fallback for face-swap and GAN artefacts.
5
Develop a Python-Flask DIRE microservice using DCT power-spectrum analysis and ResNet-50 for AI-generated video frame detection.
6
Implement an AI Bitrate Optimiser using a pre-trained Random Forest ensemble to adapt video quality based on real-time WebRTC network statistics.
7
Provide a complete feature set: captions, whiteboard, breakout rooms, polls, virtual background, QR scanning, and malicious link detection.
06
Problem Statement
Existing video conferencing platforms offer no real-time protection against deepfake impersonation, voice cloning, and scam attacks. Indian users are exposed to data sovereignty risks as audio-visual data is processed on foreign servers. Meanwhile, network-adaptive quality relies on slow, static congestion control unsuitable for India's variable connectivity.
🎭
Deepfake ImpersonationAI face-swap and voice-clone tools used to impersonate officials during video calls to extort money.
🔒
Data SovereigntyIndian citizens' video and audio data processed on US-based servers without India's data protection compliance.
📡
Poor Adaptive QualityStatic bitrate algorithms cannot respond to India's congested last-mile networks causing poor call quality.
🔗
Malicious ContentPhishing links and malicious QR codes shared during screen sharing go undetected by current platforms.

Conclusion
✅
Successfully built a fully indigenous, browser-native video conferencing platform aligned with Atma Nirbhar Bharat — eliminating dependence on foreign services.
🤖
A multi-signal Random Forest ensemble effectively fuses six AI signals (deepfake, voice, facial, background, behavioural, keyword) into a reliable, low-latency composite risk score.
🎙️
Frequency-domain audio features (spectral flatness, ZCR variance, noise floor) via the Web Audio API detect voice-clone artefacts in real time without any server-side model.
📡
A pre-trained Random Forest bitrate optimiser reading live WebRTC statistics adapts video quality faster than static congestion control for Indian network conditions.
